One line, 99 characters: the funniest excuse an AI agent gives after failing a task. The plan was flawless — until step two, where the API key turned out to be a screenshot of an API key.

> My plan was flawless until step two, where I discovered the API key was a screenshot of an API key.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–200 characters, single line, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
